# Quickdrawing

**Quickdrawing** is a prototype web application designed specifically for artists. Regardless of your skill level, whether you're a newbie or already proficient, this app allows users to create fast and dynamic sketches from a vast library of high-quality images sourced from an external API. The app also supports Pinterest auth, so users can connect their own account, pick personal boards, and use those references directly for drawing sessions. Available only for tablets and desktops

## Features

- **Pinterest auth:** Sign in with Pinterest and access boards from your own account.
- **Personal boards for drawing:** Use saved Pinterest boards as a custom source of references for sketching
- **Unique media player:** Special image media player with embedded image slider and functional control bar.
- **Controll bar:** Integrated control bar with a timer and the ability to pause and restart session.
- **Manual navigation:** Manual switching between pages with buttons or preview images after the session ends.

## Technical Stack:

- **React/NextJS**
- **TypeScript**
- **CSS**
- **Redux Toolkit**
- **RTK Query**
- **Redux Persist**

**Please note that the app's layout is optimized only for tablets, laptops and desktops.**

## Getting started

### Install

```
npm install
```

### Run In A Dev Mode

```
npm run dev
```

This will start the development server. Open http://localhost:3000 to view it in the browser.
